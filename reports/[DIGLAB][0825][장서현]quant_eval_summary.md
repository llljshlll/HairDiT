# Same-identity 정량평가 (5-모델, 4-seed)

## 실험 설정
- 대상: 동일 얼굴에 대해 헤어스타일만 스케치로 편집 (same-identity), Unbraid 466장 / Braid 107장
- HairDiT 계열(mcs2, mcs3): CRG 1.5 + BLD full (step 20) + Pixel Matte-Blend + Feathering OFF(0), epoch20
- 베이스라인 3종(HairCLIPv2 / SketchHairSalon / VividHairStyler): mcs 표와 동일 관례(Hair/Boundary/Full-portrait FID, KID_hair를 braid·unbraid 각각 따로 계산)로 평가
- seed 1, 2, 3, 42의 4-seed 평균 (단일시드 결과는 본 문서에서 제외)
- 모든 화질/경계/배경 지표는 matte 내부에서만 계산

**모델 약칭**
| 약칭 | 원 표기 |
|---|---|
| Sketch-only | mcs3 |
| Ours (Gated) | mcs2 |
| SHS | SketchHairSalon |
| HairCLIPv2 | HairCLIPv2 |
| VHS | VividHairStyler |

**데이터 유의사항**
- mcs2 값은 `--recolor_from_gt` 적용 후 mcs1/3/5/6과 100% 동일 조건으로 재생성·재평가된 값([0817] 원문 확인).
- ArcFace cos: **braid는 얼굴 검출 유효 표본이 16~20/107장뿐**(원본이 대부분 뒤통수 샷)이라 참고용으로만 보고, identity 보존력 판단은 unbraid(418~428/466장, 안정적) 기준으로 할 것.
- GT 방향오차 / Seed 불일치는 4-seed를 한 번에 묶어 계산하는 지표.
