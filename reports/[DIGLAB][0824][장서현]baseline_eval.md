# 평가 결과 정리

## same-identity
동일 얼굴에 대해 비교
Unbraid: 466장, Braid: 107장 사용

베이스라인 3종(HairCLIPv2 / SketchHairSalon / VividHairStyler)평가
Hair/Boundary/Full-portrait FID와 KID_hair는 기존 mcs 표와 동일 관례로 braid(n=107)·unbraid(n=466) 각각 따로 계산
GT 방향오차/Seed 불일치는 4-seed를 한번에 묶어 계산하는 지표라 단일시드 표에도 동일 값을 그대로 사용
> ArcFace cos: braid는 얼굴 검출 유효 표본이 16~20/107장뿐(원본이 대부분 뒤통수 샷) — braid ArcFace 값은 참고용, unbraid 기준으로 해석할 것. unbraid는 418~428/466장으로 안정적.
